# AVEXIS handoff

The project state lives in Engram (`project: tp-final`, topic `handoff/avexis-state`), updated at the end of every ticket. The collaborator's working rules live in Claude Code's local memory, which loads on its own. Neither needs to be pasted into a new chat.

Technical decisions stay in the repo, where the teacher can read them: `docs/adr/`, `GLOSSARY.md` and `docs/testing.md`.
